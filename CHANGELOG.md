# Changelog

## 1.0.0

- First public release. Saved Dock profiles, one-click apply from the editor or the menu bar, a Focus filter that switches profiles with a Focus, and .dockit export and import.
- Fixed: a second profile switch within a few seconds of the first failed and restarted the Dock twice. The cause was the kill itself: `forceTerminate()` gives the Dock about 250 ms to quit, and a Dock younger than a few seconds spends that time writing its in-memory pinned apps over what dockit just wrote. dockit now sends SIGKILL. Measured on macOS 26.4: every write followed by `forceTerminate()` or SIGTERM lost the write, every write followed by SIGKILL kept it. The Dock is gone in under 10 ms and back about 50 ms later, so a switch is also faster than before.
- Fixed: a Dock rewrite of its own preferences (same layout, new encoding) between preparing and applying a switch was treated as a user edit and stopped the switch.
- Fixed: recovery after an interrupted switch restarted the Dock even when the Dock had already relaunched with the written layout. The pending record now carries the Dock process id from before the write, and recovery skips the restart when a newer Dock is running.
- Fixed: the app learned that the Dock was back up to 100 ms late. The process poll now runs every 20 ms.
- The desktop no longer flashes black during a switch. The Dock process owns the wallpaper window, so killing it blanked every display for about 70 ms. dockit now shows the wallpaper image in a window at the desktop level from just before the kill until the new Dock has drawn its own wallpaper. The image comes from the wallpaper file macOS reports, or from the copy macOS keeps of every wallpaper chosen from a file (so a wallpaper whose original was moved or deleted still works), or from the screen when Screen Recording is already granted. Aerials and dynamic sets without that permission keep the flash. The cover windows are built ahead of time and the kill waits until the window server has them on screen plus 200 ms, so the menu bar's translucent backdrop has settled on the cover before the Dock's wallpaper window goes; recorded at 60 fps, a switch leaves no frame of the desktop, the menu bar, or the Dock strip off.
- Fixed: the menu bar icon could end up leftmost in the menu bar and be the first item macOS hid when the front app's menus were wide. The item now keeps the position it is dragged to.
- Known: macOS offers no way to reload pinned Dock items without restarting the Dock. Posting com.apple.dock.prefchanged after writing persistent-apps leaves the Dock unchanged; the Dock kept showing the old layout for five seconds with the new preferences on disk. Firefox and dockutil restart the Dock for the same reason.
- Known: the forcedTerminationAndExplicitRelaunch strategy does not work on macOS 26. NSWorkspace declines to launch Dock.app, and the probe's own recovery path failed with it. It stays selectable for the probe only.
- Known: no Homebrew cask yet. Download the DMG from the GitHub release.
